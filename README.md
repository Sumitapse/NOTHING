## 📌 What's inside

| What | Where | What it does |
|------|-------|--------------|
| **Experiments** | `/` | Throwaway scripts and snippets |
| **Environment tests** | `.devcontainer/` | Codespaces and devcontainer tweaks |
| **Tools** | `/` | Workflows and CLIs I'm trying out |
| **Breakage** | everywhere | Stuff that may stop working at any time |

> **Why "nothing"?** Because this repo *is* nothing, on purpose. If something here turns out useful, it graduates to its own repo.

* * *

## 🧪 Experiments

### Features

- **Fast to break**, fast to rewrite
- **Codespaces-first**, no local setup needed
- **Disposable**, anything can be deleted without notice

### How to use

1. Open the repo and press **Code**
2. Go to the **Codespaces** tab
3. Click **Create codespace on main**
4. Wait for the build, then run whatever you want to test in the terminal

* * *

## ⚙️ Setup

```bash
# open in a Codespace, then:
git clone https://github.com/Sumitapse/nothing.git
cd nothing
```

> **Tip:** nothing needs installing by default. Each experiment brings its own dependencies.
